# BruinPark

BruinPark is a web applicaiton that helps UCLA commuter students save money by sharing parking permits, by matching users with non-overlapping schedules. 

## Tech Stack:
- React
- Node.js / Express
- MongoDB
- Google OAuth 2.0
- Passport.js

## .env variables needed:
```env
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
MONGO_URI=
SESSION_SECRET=
CLIENT_URI=
```
